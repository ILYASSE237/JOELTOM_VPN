🚀 Installation

Installation rapide

curl -fsSL https://raw.githubusercontent.com/ILYASSE237/JOELTOM_VPN/main/autoinstall.sh | sudo bash

Installation avec Wget

wget -qO /tmp/joeltom-install.sh https://raw.githubusercontent.com/ILYASSE237/JOELTOM_VPN/main/autoinstall.sh && sudo bash /tmp/joeltom-install.sh

📌 Dépôt

https://github.com/ILYASSE237/JOELTOM_VPN.git

⚡ Installation depuis le dépôt

git clone https://github.com/ILYASSE237/JOELTOM_VPN.git
cd JOELTOM_VPN
chmod +x install.sh
sudo ./install.sh
